# Esquema Elétrico CAD - Trava EHR (Revisão R4 / ALFA)

Arquivos-fonte do esquema elétrico em AutoCAD (`.dwg`, `.dxf`), prévias em alta resolução (`.png`, `.pdf`) e scripts Python de geração paramétrica enviados pelo diretor de hardware Rafael (`PROTOTIPO ALFA/FLUXOGRAMA/ALFA R4`):

| Arquivo | Formato / Tipo | Descrição |
|---|---|---|
| `R4 FLUXOGRAMA COMUNICACAO LORA E SISTEMA DE BLOQUEIO EHR.dwg` | AutoCAD Drawing | Esquema elétrico completo editável da Revisão R4 com solenoides duplos, proteção de entrada e barramentos separados |
| `R4 FLUXOGRAMA COMUNICACAO LORA E SISTEMA DE BLOQUEIO EHR.dxf` | Drawing Exchange Format | Esquema elétrico em formato vetorial aberto para importação em qualquer ferramenta CAD/EDA |
| `R4 FLUXOGRAMA COMUNICACAO LORA E SISTEMA DE BLOQUEIO EHR - REV04 FINAL.pdf` | Documento PDF | Diagrama elétrico finalizado para impressão e consulta na bancada |
| `R4_BLOCOS_NOVOS.dxf` | Bloco DXF | Novos blocos paramétricos gerados para substituição dos atuadores e chaves MOSFET |
| `R4_PREVIA_MONTAGEM.png` | Imagem PNG | Prévia gráfica de montagem com sobreposição de camadas |
| `Simulador Trava EHR.html` | Simulador Interativo | Simulador interativo do comportamento da trava, solenoides e sensores de fim de curso |
| `build_r4_schematic.py` / `gera_blocos_r4.py` | Scripts Python | Geradores de blocos e entidades elétricas DXF para automação CAD |
